# Harvards_Artifacts
The description of Harvard’s artifact is collections of a database is a short narrative that gives context about the object. It usually includes:  what the object is, material, size, classification, color etc.
It’s a data exploration and visualization project based on the Harvard Art Museums dataset. 
Building a system that connects to a MySQL database where all the artifact data (metadata, colors, media) is stored, and then exploring or presenting it using Python + Pandas + Streamlit.
